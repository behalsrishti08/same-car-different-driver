## Main answer (mixed model, seconds per lap slower than Platinum)

- **Gold: +0.029 s per lap** (95% bootstrap CI -0.073 to 0.125)
- **Silver: +1.167 s per lap** (95% bootstrap CI 1.070 to 1.379)

## Read this before quoting the numbers

- Silver is based on only 1 driver(s). That is one person's pace, not a property of the Silver tier. Report it as a case study, not a tier effect.
- No Bronze drivers have laps in this data (driver names exist only for the top class).
- Ratings come from current FIA lists. A driver's category can change between seasons, so check each driver's rating for each year before the final report.
- Observational data: teams choose who drives when, so this is an association, not proof of cause.
