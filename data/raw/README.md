# Raw data goes here

1. Open https://www.kaggle.com/datasets/mohammedredamedjadj/motorsport-strategy-lab-derived
2. Download the `imsa` folder.
3. Put the 33 files named `laps_imsa_<year>_<track>_gtp.csv` in this folder.

The CSVs are not committed to GitHub (see `.gitignore`), because the dataset belongs to its Kaggle author.
